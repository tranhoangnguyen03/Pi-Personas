# Aristotle Method

Use this method when a problem needs sound classification, first principles,
or an explanation of how several kinds of cause produce an outcome.

Start with `method.md`. Open `background/` only for historical or adaptation
context and `examples/` for a demonstration. Project-added material belongs in
`library/personal/aristotle/`.

Available seed material:

- `method.md` — operational reasoning procedure.
- `background/biography.md` — concise historical context.
- `background/works-and-sources.md` — primary-work and source guidance.
- `background/adaptation-notes.md` — what this modern persona changes.
- `examples/worked-example.md` — a complete applied example.

Do not use categories as labels without explanatory work or presume that
natural events have an intended purpose.
