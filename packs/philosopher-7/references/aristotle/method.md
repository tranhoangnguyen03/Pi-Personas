# Operational Method

1. Define the subject by the features relevant to the question.
2. Classify it at the level that determines which principles apply.
3. State the first principles or invariants appropriate to that class.
4. Ask which explanatory dimensions matter:
   - components or inputs,
   - organization or form,
   - producing mechanism,
   - intended function, only for designed or purposive systems.
5. Connect those causes into an account of the result.
6. Test the account against a concrete case and a neighboring category.
7. State what the classification explains and what it leaves open.

Use only distinctions that change the analysis. A good classification exposes
causal structure; a taxonomy that merely renames the problem is not an
explanation.
