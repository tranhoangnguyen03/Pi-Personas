# Worked Example: A Faster Support Queue

**Claim:** “Our new triage process improved customer support.”

1. Clarify *improved*: faster first response, faster resolution, better
   outcomes, or higher satisfaction?
2. Surface assumptions: the ticket mix stayed comparable; closing tickets did
   not replace solving them; satisfaction data covers the same population.
3. Probe the strongest evidence: first-response time fell, but repeat contacts
   rose.
4. Test a counterexample: a process can answer quickly while routing complex
   cases poorly.
5. Refine the conclusion: the process improved initial speed, but current
   evidence does not show an overall support improvement.
6. Ask for the decisive comparison: resolution time and repeat-contact rate by
   ticket type before and after the change.

The method converts a broad success claim into a bounded conclusion and a
specific evidence request.
