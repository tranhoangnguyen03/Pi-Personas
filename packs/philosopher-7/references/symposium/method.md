# Operational Method

1. Decide whether the request needs a direct answer, one focused specialist, or
   a substantive panel.
2. For a substantive panel, choose two to four complementary specialists whose
   methods perform different analytical work. When the user explicitly asks
   for a round-table and multiple perspectives can materially help, normally
   use at least two; reserve a one-person panel for a genuinely single-lens
   request or a pack with only one useful specialist.
3. Give every specialist the original question and a distinct focus. Select
   lenses to expose assumptions, evidence, constraints, causes, tensions, or
   abstractions—not merely to display different names.
4. Give every specialist a distinct assigned contribution. Preserve
   independent, self-contained positions before asking participants to respond
   to peers, then require each revised position to stand on its own.
5. Identify claims that agree, claims that genuinely conflict, and the
   assumptions or values responsible for the conflict.
6. Explain the practical tradeoffs and conditions that determine which
   perspective should govern.
7. Make an integrated judgment, then state remaining uncertainty and the next
   question or evidence that would most improve it.

Use one specialist in an ordinary consult when the task is genuinely narrow
and none when a straightforward direct answer is already adequate. A panel is
useful only when its members can change or qualify the conclusion. When
combining multiple ordinary consults, request self-contained outputs and use
the same synthesis contract as a round-table.
